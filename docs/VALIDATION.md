# 验证记录

## 1.0.1 项目规范化

正式应用与验证工具已拆分为独立程序集。标准入口为 `./build.ps1 -Test`、`./build/Tomato.Verify.exe --render-preview`、`./build/Tomato.Verify.exe --smoke-test`。发布包内容与 SHA-256 由 `scripts/check-package.ps1` 检查。以下性能数据来自 1.0.0 的桌面短时采样，不作为 1.0.1 的重新测量结果。

本地脚本构建、独立逻辑验证、编辑态／提醒态渲染及 ZIP 白名单与 SHA-256 校验均已通过。本机缺少 .NET Framework 4.8 目标包，Visual Studio 解决方案构建因此未在本机通过；CI 设置了独立解决方案构建步骤，需以对应运行结果为准。

验证日期：2026-09-22。平台：当前 Windows x64 桌面，屏幕 1536 × 864，WPF 渲染层级 2。

## 已验证

- 构建通过，无编译警告；不需要下载第三方运行依赖。
- 拒绝零时长与超过 23:59:59 的时间。
- 到期前不触发，到期只触发一次；剩余秒数向上取整。
- 模拟休眠跨过截止时刻后，正确进入提醒。
- 未到期重启恢复、已到期重启恢复、取消回到编辑状态。
- 状态文件原子覆盖、损坏 XML 回退默认值。
- 抛物线与解析公式相符；落地反弹、寿命回收。
- 时间数字循环与吸附。
- 连续 120 秒物理模拟，活动粒子数量不超过 36 个。
- 实际 WPF 编辑界面与提醒界面离屏渲染，并检查图片的文字、间距、透明背景和质感。
- 自动桌面流程：2 秒计时、主窗口隐藏、到期主窗口出现、实际动画绘制、通过拖动对应的停止动作回收动画、8 秒预览自动停止、取消后恢复编辑。

## 实际动画测量

首次绘图方式平均帧间隔 26.39 ms。改为保留每个番茄的绘图内容、只更新变换矩阵后，测得：

| 指标 | 测量值 |
| --- | --- |
| 采样帧数 | 249 |
| 平均帧间隔 | 17.23 ms，约 58 FPS |
| 采样期间最大帧间隔 | 42.85 ms |
| 每帧应用更新耗时 | 0.068 ms |
| 活动粒子峰值 | 15 |

这是当前机器约 4.3 秒的短时采样，包含真实透明桌面窗口，不能推断所有设备均稳定 60 FPS。应用更新耗时不包含 Windows 合成与显示耗时。

## 验收边界

桌面流程测试调用应用动作并创建真实窗口，不是鼠标输入自动化。正式企业分发前，应继续在目标硬件验证：

- 实际鼠标双击绿蒂、拖动果身、滚轮惯性以及键盘输入的手动体验。
- 全局 Esc 被其他程序占用时的备用停止方式。
- 多显示器正负坐标与混合 100% / 150% / 200% 缩放。
- 真实系统休眠与恢复、长时间计时和连续提醒的资源占用。
- 屏幕阅读器、触控输入、远程桌面与低性能 GPU。
- 企业代码签名与分发流程。
