# 朱果 · macOS 版

[English](README.md) | 简体中文

基于 Swift、AppKit 和 SwiftUI 的原生 Mac 番茄钟，无 Electron 和第三方依赖。支持 **macOS 13 Ventura 及以上**，一个通用程序同时支持 **Apple Silicon 和 Intel**。

## 安装

在 [GitHub Releases](https://github.com/Dante9k/tomato-focus/releases) 下载 Mac DMG 或 ZIP，也可以从成功的 [macOS 构建](https://github.com/Dante9k/tomato-focus/actions/workflows/macos.yml) 下载 `tomato-focus-macos-universal`。

打开 DMG，把 **Tomato Focus.app** 拖到 Applications，或复制到其他可写目录。运行后会出现桌面番茄和菜单栏图标，不显示 Dock 图标。**首次运行默认开启“登录时启动”**，从 1.1.15 首次升级也会应用此默认值，可随时在偏好设置中关闭。macOS 可能要求在“系统设置 → 通用 → 登录项”批准；程序会显示实际注册／待批准状态，并提供跳转入口。在系统设置中移除后，不会每次启动都重新开启。升级前通过菜单栏正常退出旧版，再替换程序；设置和进行中的计时会保留。

首版为 **临时签名，尚无 Apple Developer ID 签名与公证**。macOS 可能阻止打开下载的程序。只有在确认来源并信任本仓库后，才使用苹果提供的 **系统设置 → 隐私与安全性 → 仍要打开** 单程序授权流程；不关闭 Gatekeeper、不批量移除隔离标记。参阅[苹果说明](https://support.apple.com/zh-cn/102445)。组织管理策略可能禁止运行，本程序不会绕过它。

## 使用

- 三列分别编辑时、分、秒，无可见单位标签，但保留无障碍名称。支持滚动、拖动、点击相邻数字、Tab、方向键和输入数字。逐格播放卡点声，可选 Force Touch 反馈；应用预设不播放拨轮音效。
- 待机番茄缩为 **220 × 220 逻辑点**，宽高各缩小 12%。果身、拨轮和鼠标点击范围同步缩放，选中数字约 21 点，每列宽约 42 点。
- 双击绿蒂或下方果身，或按回车开始。番茄在 460 毫秒内向自身右上角从 220 缩为 125 逻辑点，果皮透明度降到 32%，显示清晰的淡白光镂空数字，移除编辑框。浮动窗口在普通窗口上方，并跟随桌面空间显示。到时提醒恢复为 250 点；停止提醒或取消计时返回 220 点待机状态。升级保留原位置的右上角锚点。
- 拖动移动位置；拖住番茄，在同一主方向一秒内进行至少三次有效反向、每段至少 20 逻辑点，可取消计时。普通拖动不取消。菜单栏也可取消、隐藏或恢复番茄。
- 到时在当前位置恢复大小，向**番茄所在的显示器**投掷小番茄。投出与落地分别触发音效，透明动画层允许鼠标点击下方应用。拖动或双击大番茄、在番茄获得键盘焦点时按 Esc，或通过菜单栏停止提醒。
- 右击番茄或打开菜单栏的“偏好设置”：25/5/15 分钟预设，分别配置拨轮、到时、投掷音效，开关触控板反馈，预览八秒提醒。界面根据系统语言显示英文或中文。

系统开启“减少动态效果”时，禁用缩放与投掷动画、拨轮立即对齐，保留静态到时提醒及可选提示音。“减少透明度”会让果皮保持不透明。轻触反馈由 AppKit 根据当前输入设备和系统设置处理；不支持的设备正常使用声音与画面反馈。

## 数据与卸载

无需账号、联网、遥测、录屏权限、辅助功能权限或输入监控。设置保存在 `~/Library/Application Support/TomatoFocus/state.json`。保存的是实际截止时间，睡眠或退出后重新打开不会从头计时；已到期会显示提醒。程序无法唤醒睡眠或关机中的 Mac。

卸载时先在偏好设置关闭“登录时启动”，从菜单栏退出，再移除程序；默认保留设置。只有需要清除个人设置时才移除上述设置目录。Windows 和 Mac 各自使用本地设置，本版不自动同步或导入 Windows 设置。

## 开发和验证

在安装了 Xcode 命令行工具、Swift 5.9 及以上的 Mac 仓库目录运行：

```sh
bash scripts/build-macos.sh
```

脚本执行逻辑测试、双架构编译、合并通用程序、生成 Retina 图标、临时签名及签名校验、隔离环境的界面启动验证和文件白名单检查，在 `dist/` 生成 DMG、ZIP 与 SHA-256。测试状态与预览图留在 `build/macos/`。开发验证仅在显式传入参数和独立设置目录时执行，不分发额外的验证工具程序。

Mac 版本号由 `macOS/VERSION` 维护，Windows 继续使用根目录的 `VERSION`。CI 在 Apple Silicon 和 Intel 运行器上分别启动程序。登录项检查覆盖默认开启、关闭、保存、待批准、系统错误和避免重复注册；真实注册／移除 API 只在一次性 GitHub Mac 运行器执行，普通本地构建使用模拟登录项服务，不修改开发者的登录项。真实注销／登录、音效质感、Force Touch、物理输入、帧率、多显示器、桌面空间和全屏应用组合仍需实机验收；详见[验证记录](VALIDATION.md)。
